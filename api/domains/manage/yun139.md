# API · 管理面 · 139 云盘账号（yun139）

能力：**`ManageMount`**（v1 同口径 —— 139 账号归媒体库管理域）。

> **状态**：V1F-04a（段 A）已实现 —— 档案 / 池 / 成员的**存管**。
> ★ **段 A 边界**：**池不参与取流调度**（`resolve` / `lease` / `report` 属段 B，尚未接线）。
> 即：账号池可以建、可以配成员、可以看，但**取流时不会按池策略选号**。

---

## 模型（两级，与 115 不同）

115 是**挂载级单账号**（`accounts/{mount_id}`）；139 是**实例级两级模型**：

| 概念 | 语义 |
|---|---|
| **Credential Profile** | 一个 139 身份，独立于挂载；可被多个账号池引用。凭据密文走 SecretBox。 |
| **Account Pool** | 调度池：策略 + 冷却 + 并发上限 + 启停。 |
| **Pool Member** | (pool, profile) 关联：权重 / 启停 / 失败计数 / 冷却期。 |

### 状态枚举

- `status`（档案）：`Pending` ｜ `Active` ｜ `AuthExpired` ｜ `Disabled`
- `strategy`（池）：`round_robin` ｜ `least_used` ｜ `sticky_share` ｜ `failover`（默认 `round_robin`）
  - 解析别名：`round-robin`/`rr`、`least-used`/`lru`、`sticky-share`/`sticky`、`fail-over`/`fail_over`；**大小写不敏感**

### 时间格式

一律 **INTEGER 毫秒 epoch**（与 `UtcInstant::epoch_ms` 对齐；与 115 accounts 面的 ISO-8601 **不同**，前端接线时注意区分。

## 端点（11 个）

### 凭据档案

| 方法 路径 | 说明 |
|---|---|
| `GET /api/manage/yun139/credential-profiles` | 列表（`created_at DESC`）→ `{items:[…]}` |
| `POST /api/manage/yun139/credential-profiles` | 新建 → `{profile:{…}}` |
| `DELETE /api/manage/yun139/credential-profiles/{profile_id}` | 删除 → `{ok}`；**仍在池中 → `409`** |
| `POST /api/manage/yun139/credential-profiles/{profile_id}/reauthorize` | 重新授权（覆盖凭据）→ `{profile:{…}}` |

**新建 / 重新授权 请求体**（三选一，至少一项非空）：

```jsonc
{
  "display_name": "主账号",        // 可选；缺省 `139 账号 <id前8位>`
  "qr_session_id": "sess-1",        // 可选；段 A **扫码未接线** → 传它得 503
  "authorization": "…",             // 可选；有它才有 can_refresh=true
  "cookie": "…"                     // 可选
}
```

- 三者皆空 / 全空白 → `400 Validation`
- `qr_session_id` 非空且扫码源未接线 → `503 DependencyUnavailable`（段 A 实际行为：**请直接提交 `authorization`/`cookie`**）

**档案响应体** `Yun139CredentialProfileDto`：

```jsonc
{
  "id": "…",
  "display_name": "主账号",
  "account_identity_mask": "au****56",   // 掩码：仅保留前 2 / 后 2 位
  "status": "Active",
  "can_refresh": true,
  "authorization_expires_at": 1900000000000,
  "last_success_at": null,
  "last_error_at": null,
  "last_error_kind": null,
  "last_error_message": null,
  "created_at": 1700000000000,
  "updated_at": 1700000000002
}
```

> `credentials_ciphertext` **不出现在响应里**（密文不出管理面）。
> 掩码只用于展示：同一身份的两个档案会是不同的 `account_fingerprint`，但**本卡段 A 不做强制去重**（仅记录指纹，供段 B/后续卡判定）。

### 账号池

| 方法 路径 | 说明 |
|---|---|
| `GET /api/manage/yun139/account-pools` | 列表 → `{items:[…]}`（含 `member_count`） |
| `POST /api/manage/yun139/account-pools` | 新建 → `{pool:{…}}`；同名 → `409` |
| `GET /api/manage/yun139/account-pools/{pool_id}` | 详情 → `{pool:{…}}` |
| `PUT /api/manage/yun139/account-pools/{pool_id}` | 更新（PATCH 语义，只覆盖传入字段）→ `{pool:{…}}` |
| `DELETE /api/manage/yun139/account-pools/{pool_id}` | 删除（级联成员）→ `{ok}` |

**池请求/响应体**：

```jsonc
// 新建
{ "name": "主池", "description": "…", "strategy": "least_used",
  "cooldown_seconds": 60, "max_concurrent": 3 }
// 更新（全可选）
{ "name": "…", "description": "…", "strategy": "failover",
  "cooldown_seconds": 60, "max_concurrent": 4, "is_enabled": false }
```

```jsonc
// 响应 Yun139AccountPoolDto
{
  "id": "…", "name": "主池", "description": "备注",
  "strategy": "least_used", "cooldown_seconds": 60, "max_concurrent": 3,
  "is_enabled": false, "member_count": 2,
  "created_at": 1700000000000, "updated_at": 1700000000001
}
```

校验：`name` 空 → `400`；`cooldown_seconds < 0` → `400`；`max_concurrent <= 0` → `400`；`strategy` 非法 → `400`；同名 → `409`。
默认：`strategy=round_robin`、`cooldown_seconds=300`、`max_concurrent=2`、`is_enabled=true`。

### 池成员

| 方法 路径 | 说明 |
|---|---|
| `GET /api/manage/yun139/account-pools/{pool_id}/members` | 成员列表 → `{items:[…]}` |
| `POST /api/manage/yun139/account-pools/{pool_id}/members` | 添加成员 → 返回更新后的 `{items:[…]}` |
| `DELETE /api/manage/yun139/account-pools/{pool_id}/members/{profile_id}` | 移除成员 → `{ok}` |

```jsonc
// 添加
{ "profile_id": "…", "weight": 3 }   // weight 可选，默认 1；<=0 → 400
```

```jsonc
// 成员响应 Yun139AccountPoolMemberDto（带档案展示信息）
{
  "pool_id": "…", "profile_id": "…",
  "profile_label": "甲",            // 档案 display_name
  "profile_status": "Active",        // 档案 status
  "weight": 3, "is_enabled": true,
  "last_used_at": null, "fail_count": 0, "cooldown_until": null,
  "created_at": 1700000000000, "updated_at": 1700000000000
}
```

成员指向不存在的档案或池 → `404`（不静默创建）。

## 装配与错误

- 服务**未装配**（`FMBY_SECRET_BOX_KEY` 不可用）时，全部端点返回 **`404`**
  （`fail-closed`：不回落无凭据假实现）。前端应把 404 当「功能未启用」提示，而非错误重试。
- 删除档案而它仍被池引用 → `409 Conflict`，提示先移出成员（v1 同语义）。
